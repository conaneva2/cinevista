# 开发任务簿

本文件是开发执行计划，不是已完成清单。已知实现与限制见根目录 PROJECT_STATUS.md；产品与架构要求见 docs/02_ARCHITECTURE.md 和 docs/15_NATIVE_PERSISTENCE.md。每个任务只交付实际证据；硬件阻断不妨碍完成独立主机任务。

本Mac执行更新（2026-09-19）：T00、T01已完成；T02必要过渡检查已实现但完整资格仍进行中；T03未检测到Sony设备且安装器尚待审查。实际APK、测试和阻断见PROJECT_STATUS及`handoff/runs/20260919T141703Z/SESSION.md`。下面的“初始状态”保留原交接计划含义，以task-board.json为当前状态。

开始顺序：T00 → T01（T02可并行）→ T03；T04可先做纯解析。T05/T06将重启原生直拍尽早证明；T10/T11先做小探针，不等所有颜色或UI完成。T08标定准备可在取样前做，完成必须有真实样片。

交付一个任务时更新本任务板和 PROJECT_STATUS。所有源码修改运行统一check；设备代码还需真实SDK构建；未测试设备保持unknown。外部发布和硬件持久写入按用户授权执行。

## T00｜基线接手与独立复跑

**优先级：P0｜前置：无｜完成是否需要相机：否｜初始状态：未开始**

确认源码/工作树，不重建空项目；先保存历史证据，再执行环境与主机检查。

影响范围：`handoff`、`tools`、`evidence`。

### 必须产出

- 基线哈希核验
- 用户Mac的环境报告
- 独立run-id日志
- 实际已完成/欠项表

### 完成判据

- 191个原文件保持可追溯；本地用户改动没有被覆盖
- 实际运行doctor/check并记录退出码
- 最新目标以ADR0011为准
- 没有把Linux历史结果当用户Mac通过

### 必测反向/禁止替代

- 工作区有用户改动时先保存/报告，不reset --hard
- 日志写入新目录，不覆盖历史后称为旧结果

## T01｜Mac真实SDK与第一个开发APK

**优先级：P0｜前置：T00｜完成是否需要相机：否｜初始状态：未开始**

复核Recipe Lab构建路径，取得可信平台库和官方工具；实际走完类型编译、资源、DEX、对齐、签名、检查。

影响范围：`tools`、`config`、`.github`、`app/AndroidManifest.xml`。

### 必须产出

- 工具链精确版本与已取得的hash
- 真实构建日志
- 可验签开发APK或明确失败点
- 本地签名身份指纹（不含私钥）

### 完成判据

- 非语法解析：所有Android源真实SDK编译成功才标构建成功
- 记录DEX/minSdk/targetSdk/权限/类定义及签名
- 构建产物名称与Manifest一致
- 若缺可信API10包，提交可验证替代ADR，不伪造SDK

### 必测反向/禁止替代

- 不因Apple Silicon把相机ABI改成arm64-v8a
- 不为了构建关闭SIP/Gatekeeper或下载来源不明修复SDK
- 不以JDK新版本推导相机新API可用

## T02｜升级过渡期规范与证据门禁

**优先级：P0｜前置：T00｜完成是否需要相机：否｜初始状态：未开始**

保留纯Java探针检查；为已审查的JNI/API可选路径设计严格例外。历史unknown断言改为fixture+证据一致性测试。

影响范围：`tools/check_app_source.py`、`tools/inspect_apk.py`、`tools/release_check.py`、`tests/tools`、`config`。

### 必须产出

- 检查策略与构建profile
- 状态证据schema校验
- 必要ADR
- 正向/负向工程测试

### 完成判据

- 未经批准的native库/ABI/包定义仍会失败
- implemented或verified必须有相应能力证据；不是永远要求false
- 门禁报告绑定型号/固件/构建/参数指纹，检查路径和hash
- 启用的软件增强功能须有自己的验收，不能忽略optional_features

### 必测反向/禁止替代

- 伪造verified、只建空证据文件、指向仓库外路径均应拒绝
- 不删除check、不把失败变continue-on-error
- 不因写入字符串出现就误判已审查的native profile，也不放开全部Backup

## T03｜USB安装、运行时与摄影基础探针

**优先级：P0｜前置：T01｜完成是否需要相机：是｜初始状态：未开始**

影响范围：`sony`、`camera-api`、`app`、`device-reports`。

### 必须产出

- 实际型号/固件/SDK/显示和按键记录

- 单次原生捕获及回执记录

### 完成判据

- API10构建约束与设备SDK事实分开

- 回执不自动提升为源文件确认
- 正常退出不留下无法恢复的相机占用

### 必测反向/禁止替代

- 不默认已有Wi-Fi ADB、USB ADB或旧Mac驱动
