# ADR 0014：先鉴定机内实时反挤压，保留设备操作暂停

日期：2026-10-22。状态：采用。只调整当前工作顺序与验收门槛；不撤销既有产品要求。

## 问题与用户决定

用户明确项目主要价值是机身内实时反挤压；若不具备实现可能，其他功能不足以支持继续制作。当前要求结合既有固件和源码调查两条路径，先不要操作相机。这覆盖 ADR0011 和旧任务顺序中“原生颜色持久化先行”的当前优先级，不表示取消颜色需求。

## 候选与决定

1. 改变原生预览层比例：保留研究，但普通预览的特殊格式描述信息、窗口尺寸请求和 DisplayManager 查询方法，尚未建立实际视频非等比缩放链，不能作为已可用后端。
2. CameraSequence 取得预览帧后自绘：官方 4.01 SmartRemote 有实际 JPEG 取帧及复制代码，作为优先候选。第三方访问、机内解码/绘制性能、LCD/EVF和拍摄共存仍未知，不承诺最终可用。

以 T11 的内容比例、动态内容帧率/延迟、取景输出与正常退出证据作为继续扩大开发的门槛。离线阶段不以图形接口存在替代硬件验收，也不以尚未找到原生缩放接口宣告硬件绝无可能。先记录可复核的离线结果，不新增相机后端或固件补丁。

## 验证与限制

证据：`handoff/runs/20261022T014755Z-desqueeze-feasibility/FINDINGS.md`。本轮没有操作相机，未安装 APK、未刷写固件。`.local/CAMERA_WRITE_HOLD` 保留；离线发现可用候选不会自动解除事故暂停。

## 后果与撤销

颜色/界面开发不再替代首要可行性问题。若后续硬件证据否定候选路线，应按用户目标重新判断是否继续项目，而不是把外接显示或静态回放改称完成。只有新的用户决定或经核验的证据才调整此门槛；不删除事故和失败记录。
