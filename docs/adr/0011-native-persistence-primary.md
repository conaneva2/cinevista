# ADR 0011：原生持久化颜色成为主交付，实时样张创作保留

日期：2026-09-19。状态：采用为产品与工程约束；硬件能力未验证。

替代 ADR0010 的“软件 LUT 后端为生产主线”决定，不撤销实时预览和数据一致性要求。

用户明确要求退出幕野、正常关机重启、不再启动 App、原生拍照时外观仍生效。现有软件 LUT 工具不能独自实现。决定以机型/固件适配的原生持久参数为首版目标，保留软件 LUT 作为创作目标与增强版；可表达范围和预览精度不得混淆。运行时硬件矩阵曲线独立研究，不能因 ISP 使用而推定有持久化。

Studio 原生适配预览需标定；当前渲染器仍明确标为软件参考。无法原生表达的调色必须展示适配差异，不得静默降级或强制用户接受。

Recipe Lab 的授权范围内复用持久化机制，但只能写经过目标机型/固件鉴定的必要字段。允许研发这个受控能力，不再笼统禁止一切持久写入；未知槽位、保护绕过、固件改造和自启动替代方案仍禁止。

Film Studio 非商用新增代码不进入 MIT 工程。其 A7R II API16 记录仅作第三方证据，读取实际运行时后再选可选后端。

详见 docs/15_NATIVE_PERSISTENCE.md、docs/16_NATIVE_COLOR_VALIDATION.md。发行门禁增加退出、重启原生拍摄、恢复与原生预览匹配；所有新门禁当前 unknown。不以主机测试或作者声明填 verified。
