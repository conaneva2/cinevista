# ADR 0010：Studio 以实时样张调色为主，而非只写原生参数

日期：2026-09-19；状态：采用，Camera 执行仍待实测。

用户明确要求实时看到导入样张的变化，然后导出给相机。

决定：保留 CS/PP 原生编写台作为辅助页；软件工作区成为 Studio 默认入口。预览采样生成的 LUT；导出同一 Float32 表，固定 sRGB 全范围和三线性插值。未完成的原生仿真不能被 CSS 或近似 HSL 冒充。

后果：相机必须新增软件 LUT 后端。不能声称产物可以上传到 Sony PP，不能声称新增一个 LUT 就保持原生 JPEG 同速。数据包导入与单图往返成为发布门禁。修改限制和运行时性能需独立证据，不能以“已经导出文件”代替。

原片、机型能力分级、离线与模块隔离要求不变。
