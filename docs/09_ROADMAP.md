# 09｜后续任务与退出条件

## P0-1 工具链资格：立即优先
获取合法API10 SDK，固定JDK/BuildTools精确分发与哈希；运行doctor/android，修正真实编译错误，审查DEX与签名；记录安装机型/固件。不得修改minSdk以逃过错误。出口是可检查的开发APK，不是成品支持承诺。

## P0-2 三个机身实验并行最小化
原生取景/单拍保存关联；真实影像非等比显示；小图到原生优化裁切/缩放/JPEG输出。一个实验一个结果，不把失败藏在产品大界面。读取像素路线与Sony native输出各自决定是否需引入libyuv/libjpeg。

## P1 复用导入
Recipe Lab固定配方与mapping提取，严格门控；OpenMemories媒体读取/显示必要部分；完整保留来源。完成色彩稳定与RAW/曝光策略测试。JPEG.CAM只吸收经过review的分行处理经验；有必要才移植代码。

## P2 宽幅闭环
统一几何+UI校准+源确认+安全JPEG输出+App内真实回看。以一张原图完整闭环证明可用，然后才增加队列和快捷键。

## P3 变形摄影闭环
真实desqueeze、对焦检查、EVF和成片一致性。若背屏路径不能实现，提交失败证据/替代ADR；不能悄悄删掉目标把黑边当完成。

## P4 产品打磨与发布
用户操作测试、收藏配方、启动/恢复体验、日志脱敏、许可证、签名/更新、兼容矩阵。视频和HDMI单独研究。不得以新增配方数替代核心质量。

每项完成都更新PROJECT_STATUS与能力台账。任务描述不包含虚构工期、用户硬件或测试通过记录。
