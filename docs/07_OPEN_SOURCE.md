# 07｜开源、来源与维护

幕野原创代码使用MIT，根LICENSE已落盘，版权集体标注为CineVista contributors，不臆造用户名/公司。既有PMCADemo改编代码保留其2015 ma1co版权；Recipe Lab为2026 André Domingues；OpenMemories为2016 ma1co。具体文件以third_party许可副本为准。

MIT不是强制衍生项目继续开源的许可。我们选择主动开源并回馈上游，但不对他人增加与MIT矛盾的使用限制。软件许可、品牌、照片、LUT、纹理、字体各自审核；本包不含字体文件、不复制竞品UI资产、不包含用户照片或密钥。

## 每份依赖的最小记录
仓库/官方URL、精确提交或版本、采用文件、SHA256清单、许可证原文、原作者声明、修改说明、设备兼容证据、更新/安全责任人。

`upstreams.lock.json`区分采用决定、已包含代码、vendor拷贝；null提交只是研究候选，不能进入生产发布。SDK/工具链条款单独处理，不能随着MIT工程任意重分发。

## 引入方式
优先锁定源码快照+完整来源记录，或使用固定提交submodule。配方可由有版本的数据导入过程生成本地目录，保留原数据与变更diff；不在相机运行时联网下载并执行任意代码。

不整包合并JPEG.CAM，不复制网站、字体、LUT集合；若选其中代码，先完成文件级许可复核、冻结相关来源、补测试并在提交中标注。发现上游通用问题时优先提issue/PR，而不是长期维护无记录的私有分叉。
