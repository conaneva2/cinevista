# 幕野 CineVista 使用说明书

适用：Studio软件0.2 Alpha、相机0.4-probe开发探针。工程当前可用范围见[项目状态](../PROJECT_STATUS.md)。尚无相机实测；本说明不承诺相机兼容。

## Studio：导入样张创作自己的颜色

1. 在Mac打开`studio/CineVista_Studio_Realtime_0.2.html`或`studio/index.html`。单文件离线运行，不需要账号或上传照片。
2. 导入本地JPEG/PNG样张，保持输入为已知sRGB、普通非Log影像。当前不支持RAW显影、完整P3/HDR/ICC工作流。
3. 调节亮度、曲线、颜色控制，观察实际像素变化；用原图/当前/分屏或按住原图比较。软件创作偏色不等于Sony白平衡或PP菜单参数。
4. 最多六张样张切换，检查肤色、暗部、天空等不同场景；可撤销/重做。预览代理尺寸影响画面大小，17³/33³决定LUT节点精度。
5. 保存CVG保留可编辑工程；导出CUBE为颜色表；CVP为软件颜色素材包草稿。预览PNG是预览输出，不是完整原尺寸照片交付。保留原片和工程备份。

| 格式 | 用途 | 当前限制 |
|---|---|---|
| CVG | 再次打开编辑软件调色工程 | 非机身预设 |
| CUBE | 软件LUT | 不等于原生PP/CS |
| CVP | LUT及输入基线说明 | 相机解析/执行尚未实现 |
| CVL | 原生语义参数草稿，旧native.html编写台 | 相机导入/持久发布尚未实现 |

原生适配预览须来自将发布的有效参数和真实标定模型；当前模型没有完成。不要将软件效果或参数填写表理解为重启原生直拍成果。个人创作颜色不因工具MIT而自动公开授权。

探针中的人工JPEG实验是小图参考；取景遮框未做光学校准，Surface倍率请求未证明实际内容变换。普通镜头1×不能为填框拉伸；65:24/2.39和真实变形倍率应独立。背屏通过也不能推导EVF通过。

当前探针没有持久颜色写入。最终需要发布→退出→正常关机重启→不进入App原生拍摄，以及必要字段恢复；现在不能执行不存在的发布按钮。

## 故障处理与反馈

| 现象 | 当前处理 |
|---|---|
| 软件预览与预期不同 | 检查输入基线、当前样张、LUT精度；用原图分屏比较，不将已调色JPEG当可逆RAW |
| 浏览器文件打开失败 | 记录浏览器版本和错误；不关闭浏览器/系统安全设置，保留文件供排查 |
| 相机黑屏、卡错误或占用无法释放 | 停止继续实验，记录步骤；等写卡结束，正常退出/关机，不在写卡中拔电池 |
| 有拍照回调但找不到图片 | 记录回执与原生回放实际结果，不猜最新文件、不删除原片 |
| release-check非零 | 当前机测/发行门禁未完成，属于预期阻断；开发APK和主机检查分开判断 |

反馈包含版本、做到的步骤、预期/实际、脱敏错误；不附密钥、GPS、序列号或未经授权照片。真实样片默认留本机。该版本未提供稳定版升级/卸载认证，保持本地开发签名身份以便未来同包更新。

## 中文取景页操作（新版开发APK）

首页选“2. 取景与单次拍摄探针”。左右键选择镜头/画幅/设置，中键激活；“镜头”循环1.0/1.33/1.5/1.6/1.8/2.0倍，“画幅”循环65:24/2.39/自然画幅。两者独立。物理快门仍限定每次进入页面一次拍摄；回执不等于原片确认。

设置中可开关Surface尺寸实验、重新启动取景、查看完整诊断、返回首页。尺寸实验默认关闭且未证明真实内容变换；普通拍摄请先保持1.0倍。若相机打开失败，返回首页看诊断，再重新进入，不会静默替换成模拟相机。菜单/返回键行为仍需真机验证。

“默认中文”目前表示应用提供完整中文默认资源；尚未加入英语资源或语言选择。原始设备信息/错误细节可能包含英文，合成测试靶方向标识保留英文。相机系统语言不受影响。
