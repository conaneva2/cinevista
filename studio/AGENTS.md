# Studio 局部规则

这里是Mac端开发，不能把JavaScript或浏览器代码塞进Android相机。look-core.js是当前参数契约，studio.js只负责界面。先运行node --test studio/tests/*.test.js。

原生参数编辑不得用CSS/filter、猜测的曲线或软件HSL伪装为Sony精确预览。PP Color Depth不等于六色HSL。软件LUT区未来独立实现、单独标明范围。不得擦除改编来源，不得让文件作者伪造device verified，不得直接访问相机或浏览全部磁盘。

当前只是配方编写台，.CVL Camera importer未实现；所有按钮、说明和发布文字必须与此一致。不引入网络或CDN资源。
